## 📌 Project Overview
Cancellations pose substantial operational inefficiencies and revenue loss in the hospitality sector. This project focuses on predicting whether a hotel booking will be canceled in advance based on customer booking patterns, lead time, deposit type, market segment, and historical reservation characteristics.

---

## 🔬 Methodology & Workflow

1. **Exploratory Data Analysis (EDA)**:
   - Statistical summaries, distribution analysis, and correlation mapping.
   - Lead time impact, deposit type tendencies, and customer segment cancellation patterns.
2. **Data Preprocessing & Feature Engineering**:
   - Handling missing values, categorical encoding, and feature scaling.
   - Multicollinearity resolution and train/validation/test splitting.
3. **Model Implementation & Benchmarking**:
   - Supervised classification algorithms evaluated:
     - Logistic Regression
     - Decision Trees
     - Random Forest Classifier
     - Naive Bayes Classifier
     - Gradient Boosting / Ensemble models
4. **Performance Evaluation**:
   - Evaluated across Accuracy, Precision, Recall, F1-Score, and ROC-AUC metrics.

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/RedRabies/CSE422-Hotel-Booking-Cancellation-ML.git
   cd CSE422-Hotel-Booking-Cancellation-ML
   ```
2. Set up virtual environment and install dependencies:
   ```bash
   pip install numpy pandas matplotlib seaborn scikit-learn jupyter
   ```
3. Launch Jupyter:
   ```bash
   jupyter notebook
   ```
   Open `CSE422_Group11_21201675_22301737.ipynb` and run all cells.
